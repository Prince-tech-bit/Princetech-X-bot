<h1 align="center">🐺 PRINCETECH-X BOT</h1>

<p align="center">
  <strong>WhatsApp Automation Bot by PRINCETECH</strong>
</p>

<p align="center">
  A Node.js WhatsApp bot with command management, database support,
  anti-spam controls, defensive security features and multiple deployment options.
</p>

---

## 🚀 FEATURES

- 🤖 WhatsApp automation
- ⚡ Fast command handling
- 🧩 Command registry
- 📋 800-command catalog
- 🗃️ Database support
- 🛡️ Anti-spam and rate limiting
- 🔐 Authentication-state storage
- 🚨 Defensive hijack-protection features
- 📊 Command usage tracking
- 🚫 User blocklist support
- 🐺 PRINCETECH-X branding
- 🚂 Railway deployment support
- 🖥️ Render deployment support
- 🐳 Docker support
- ☁️ Heroku configuration

> **Note:** The 800-command catalog is a command framework/catalog. It does not mean that all 800 entries are fully implemented features.
